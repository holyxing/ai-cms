# 05 - 开发路线图

> 阶段划分 + 每阶段任务清单 + 工时估算（单人/小团队）

---

## 总览

| 阶段 | 周期 | 目标 | 完成后能做什么 |
|---|---|---|---|
| **P0 脚手架** | 1 周 | 项目跑起来，能登录 | 启动 + 注册 + 登录 + 看到一个空后台 |
| **P1 多站点 + 内容** | 2 周 | 手动建站 + 写文章 + 富文本 | 不靠 AI，手动完成"建站 → 写文章 → 发布" |
| **P2 主题与发布** | 2 周 | 5 个主题 + 调样式 + 静态生成 | 完整闭环，可演示给用户看 |
| **P3 AI 加持** | 2 周 | AI 写作 + AI 改样式 | AI 是核心差异化，上线就能讲故事 |
| **P4 打磨** | 1 周 | UX/性能/安全 | 准备内测 |

**总计**：8 周（单人） / 5-6 周（2 人）

## 风险预警

| 风险 | 应对 |
|---|---|
| Tiptap + 自研 block schema 对齐花时间 | 严格按 Tiptap JSON，先实现基础 6 种，其他后续 |
| Astro 模板每个主题都要写一份 | 用一套模板 + 主题切换（用 token 控制），不写多套 |
| AI 输出不稳定 | 强 JSON mode + 后处理校验 + 兜底模板 |
| Ollama 镜像大 | 默认 profile 不含，文档说明按需启用 |
| Celery 在小项目过重 | 评估用 arq（轻量），但 Celery 生态更熟 |
| SSG 构建慢 | 增量构建（V2），MVP 全量构建够用 |
