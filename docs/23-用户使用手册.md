## 1. 5 分钟快速上手

### 1.1 登录

打开后台 URL（一般是 `https://admin.example.com`），输入邮箱 + 密码登录。

- 首次登录后建议去 **设置 → 个人** 改默认密码
- 忘记密码：联系 super admin 重置（P5 会加自助找回）

### 1.2 第一次进入 — 该做什么

按顺序走：

| # | 动作 | 位置 |
|---|------|------|
| 1 | **创建站点** | 左下角 "管理所有站点" → 右上 + 新建 |
| 2 | **设置站点基本信息** | 站点名 / slug / 描述（slug 用于 URL，不能改） |
| 3 | **创建栏目** | 进站点 → 左栏 + 新建栏目（顶级 / 子级） |
| 4 | **绑定域名**（可选） | 站点设置 → 域名（生产需要，否则用 admin 域预览） |
| 5 | **写第一篇文章** | 进栏目 → 右上 + 新建文章 |
| 6 | **发布** | 文章内 → "发布" 按钮 → 全站发布 |

## 2. 核心概念

### 2.1 五个层次

| 概念 | 类比 | 数量 | 谁拥有 |
|------|------|------|--------|
| **站点 (Site)** | 一个网站 | 1-N | super_admin 或 site_owner |
| **栏目 (Category)** | 网站的菜单 / 目录 | 每个站 1-N | 站点内成员 |
| **内容 (Content)** | 一篇文章 / 一个页面 | 每个栏目 0-N | 编辑者 |
| **模板 (Layout)** | 内容的 HTML 骨架 | 每个 scope 多个 | 站点内成员 |
| **媒体 (Media)** | 图片 / 视频 / 文件 | 跨站共享 | 全员 |

### 2.2 站点 (Site)

- **独立的内容容器**：每个站有自己的栏目、内容、模板、域名
- **绑定域名**：可以是 `example.com`、`blog.example.com`，也可以绑多个
- **发布单位**：站点级发布（全站静态化）是最常用的
- **owner**：站点的所有者，拥有全部权限

### 2.3 栏目 (Category)

- **树状结构**：顶级栏目 → 子栏目 → 孙栏目（最多建议 3 层）
- **导航来源**：默认从顶级栏目生成主导航
- **slug**：栏目 URL 的一部分（如 `example.com/news/`），建后不可改
- **template**：可指定不同的模板（默认 / 卡片墙 / 自定义）

### 2.4 内容 (Content)

- **核心单位**：一篇文章、一个产品页、一个关于页
- **绑定栏目**：内容可以绑 1-N 个栏目（多栏目共享）
- **状态机**：见 §5
- **可版本化**：每次保存都会留版本（历史可回滚）

### 2.5 模板 (Layout)

- **scope + code 标识**：`scope` = home/content/category/page，`code` 是模板名
- **HTML + Design Tokens**：模板是 HTML 源码 + 一组设计变量
- **占位符**：用 `HY_xxx` 标签插入动态内容（详见 [19-标签使用手册.md](./19-标签使用手册.md)）

## 3. 日常创作流程

### 3.1 写一篇文章的标准流程

```
① 进栏目页（左栏选）
   ↓
② 点右上 "+ 新建文章"（或 ⌘N，V2）
   ↓
③ 写标题 → ⏎
   ↓
④ 选模式（HTML / AI / 预览）
   ├─ HTML 模式：直接用富文本工具栏（粗体/列表/插图/链接）
   ├─ AI 模式：打开右下角浮窗 AI 助手，对话式改写/扩写/润色
   └─ 预览：看实际渲染效果（用 site 当前 theme）
   ↓
⑤ 填右侧栏元数据：
   - 副标题（SEO 摘要用）
   - 分类标签
   - 封面图（媒体库选）
   - 发布时间（立即 / 定时）
   ↓
⑥ 点 "保存"（⌘S）
   ↓
⑦ 点 "发布"（走发布流 → 静态化 → 上线）
```

### 3.2 编辑器三模式

| 模式 | 适合 | 工具 |
|------|------|------|
| **HTML** | 直接编辑内容 | Tiptap 富文本（粗体/斜体/列表/链接/图片/代码块） |
| **AI** | 改写 / 扩写 / 翻译 | 浮窗 AI 助手 + 15 个任务 |
| **预览** | 看发布效果 | iframe + 当前主题渲染 |

**切换方式**：编辑器顶部 tab 切换 / `⌘1/2/3`

### 3.3 自动保存 vs 手动保存

- **手动保存**：`⌘S` 或点 "保存" 按钮 → 立即写库 + 留版本
- **自动保存**：编辑停止 2 秒后 → 自动写库（不留版本）
- **版本**：每次手动保存留一版，可在 "历史" 面板查看 / 回滚

## 4. AI 助手（15 个任务）

> AI 助手是**跨页全局浮窗**，点右下角 🤖 或顶栏 "AI" 按钮唤出。
> 支持多个 AI 模型（OpenAI / Anthropic / Claude / 通义千问 / Ollama 本地），
> 在 **设置 → AI 模型** 切换。

### 4.1 写作类（5 个）

| 任务 | 何时用 | 输入 | 输出 |
|------|--------|------|------|
| **起稿** | 空白文章想快速产出一版 | 标题 + 大纲 | 完整文章 |
| **改写** | 一段文字想换说法 | 选中文本 | 改写后版本（diff） |
| **扩写** | 太短想加内容 | 选中文本 | 扩写后版本 |
| **缩写** | 太长想精简 | 选中文本 | 缩短后版本 |
| **润色** | 想更专业 / 通顺 | 选中文本 | 润色后版本 |

### 4.2 翻译 / 格式化（2 个）

| 任务 | 何时用 | 输入 | 输出 |
|------|--------|------|------|
| **翻译** | 翻成英文 / 其他语言 | 选中文本 | 译文 |
| **格式化 HTML** | 内容里脏 HTML 想清理 | 选中文本 | 干净的 HTML |

### 4.3 导入类（3 个）

| 任务 | 何时用 | 输入 | 输出 |
|------|--------|------|------|
| **导入 Word** | 已有 .docx 想搬到 CMS | .docx 文件 | 文章 + 提取的图片 |
| **导入 PDF** | 已有 PDF | .pdf 文件 | 文章 + 提取的图片 |
| **导入 HTML** | 粘贴网页源码 | HTML 字符串 | 文章 + 清理后的样式 |

### 4.4 设计类（4 个，仅模板编辑页）

| 任务 | 何时用 | 输入 | 输出 |
|------|--------|------|------|
| **AI 优化设计** | 模板整体视觉太丑 | 当前 HTML + tokens | 重新设计版本 |
| **响应式补全** | 移动端布局崩 | 当前 HTML | 加 `@media 768px` 样式 |
| **a11y 增强** | 想让残障人士能访问 | 当前 HTML | 加 `alt / aria / role / semantic` |
| **SEO 增强** | 想让搜索引擎更友好 | 当前 HTML | 加 `canonical / og / Twitter / JSON-LD` |

### 4.5 内容运营类（1 个）

| 任务 | 何时用 | 输入 | 输出 |
|------|--------|------|------|
| **审计** | 发布前最后检查 | 当前内容 | 拼写 / SEO / 可读性报告 |

### 4.6 使用方法（5 步）

```
① 选中要处理的文本（写作类需要） / 或直接打开 AI 面板（设计类需要当前页面）
   ↓
② 点右下角 🤖 唤出 AI 助手
   ↓
③ 选任务（卡片式列表，hover 看说明）
   ↓
④ 看 AI 输出流（SSE 实时打字）
   ↓
⑤ 看 diff 预览 → "采纳" 或 "拒绝"
```

**采纳**：写入当前内容 / 模板
**拒绝**：丢弃，保留原文

### 4.7 AI 历史

- **位置**：顶栏 AI → "AI 运行历史" / 或 `/admin/ai/runs`
- **可查**：每次运行的 prompt、输出、token 用量、状态
- **可重跑**：点 "重新运行" 按钮
- **可采纳/拒绝**：如果之前忘了处理

## 5. 内容状态机

一篇文章的完整生命周期：

```
   ┌──────┐  送审   ┌─────────┐  通过   ┌───────────┐
   │ 草稿 │ ──────→ │ 待审核  │ ──────→ │ 已发布    │
   │draft │         │ pending │         │ published │
   └──┬───┘         └────┬────┘         └─────┬─────┘
      │                  │ 撤回              │ 取消发布
      │                  ↓                   ↓
      │               ┌──────┐          ┌──────┐
      │               │ 草稿 │          │ 草稿 │
      │               └──────┘          └──────┘
      │
      │  定时发布
      ↓
   ┌──────────┐  到点   ┌───────────┐
   │ 计划发布 │ ──────→ │ 已发布    │
   │scheduled │         │           │
   └────┬─────┘         └───────────┘
        │ 归档
        ↓
   ┌────────┐   还原   ┌──────┐
   │ 已归档 │ ──────→ │ 草稿 │
   │archived│         │      │
   └────────┘         └──────┘
```

### 5.1 5 个状态

| 状态 | 含义 | 谁能看到 |
|------|------|----------|
| **草稿 (draft)** | 编辑中，未公开 | 作者 + 站点成员 |
| **待审核 (pending)** | 已提交，等审核人批准 | 作者 + 审核人 |
| **计划发布 (scheduled)** | 设置了未来发布时间 | 作者 + 站点成员 |
| **已发布 (published)** | 已上线，公开可访问 | 所有人 |
| **已归档 (archived)** | 不再公开但保留 | 作者 + 站点成员 |

### 5.2 各状态可执行的动作

| 当前状态 | 可执行 |
|----------|--------|
| 草稿 | 发布 / 送审 / 定时发布 |
| 待审核 | 撤回（→草稿）/ 通过发布 |
| 计划发布 | 立即发布 / 归档 |
| 已发布 | 取消发布（→草稿）/ 归档 |
| 已归档 | 还原（→草稿） |

### 5.3 审核流程（多人团队）

```
作者 ─送审→ 审核人 ─通过→ 发布
        ↓
        撤回 → 草稿（作者继续改）
```

- 角色 `editor` 可以送审
- 角色 `owner` / `super_admin` 可以审核通过
- 角色 `viewer` 只能看不能改

## 6. 模板与主题

### 6.1 模板是什么

模板 = **HTML 源码** + **设计变量 (tokens)**，定义了内容怎么渲染。

例：
```html
<!DOCTYPE html>
<html>
<head>
  <title>HY_CONTENT_TITLE · HY_SITE_NAME</title>
</head>
<body>
  <article>
    <h1>HY_CONTENT_TITLE</h1>
    <div class="meta">HY_CONTENT_DATE · HY_CONTENT_CAT</div>
    <div class="content">HY_CONTENT_BODY</div>
  </article>
</body>
</html>
```

`HY_xxx` 是占位符，发布时被替换成实际内容。完整列表见 [19-标签使用手册.md](./19-标签使用手册.md)。

**ZIP 导入**：每个栏目分组默认只生成 **1 份列表模板 + 1 份详情模板**（如「新闻」栏目共用一套），不会为 ZIP 里每个 HTML 各建一份。详见 [18-布局系统与标签占位符.md §7.5](./18-布局系统与标签占位符.md)。

### 6.2 改样式（无需碰代码）

打开模板编辑器 → 右侧 "样式" 面板：

| 操作 | 说明 |
|------|------|
| **选主题** | 顶部下拉选预设（default / card / minimal...） |
| **改颜色** | 点色块 → 选色器 → 实时预览 |
| **改字体** | 字体下拉 → 实时预览 |
| **改间距** | 滑块调 padding / margin |
| **改圆角** | 滑块 |

改完自动保存，无需手动点保存。

### 6.3 AI 改样式（自然语言）

模板编辑器 → 唤出 AI → 选 "AI 优化设计"：

```
输入: "改成深色模式，蓝色调，圆角加大到 12px"
输出: 整页 diff 预览 → 点 "采纳"
```

### 6.4 模板 scope 分类

| scope | 作用 | 数量 |
|-------|------|------|
| `home` | 站点首页 | 通常 1 个 |
| `category` | 栏目页 | 每个栏目可指定 |
| `content` | 内容详情页 | 通常 1 个 |
| `page` | 单页（关于/联系） | 0-N |

## 7. 发布与回滚

### 7.1 三种发布粒度

| 粒度 | 速度 | 何时用 |
|------|------|--------|
| **全站发布** | 慢（10-30s/站） | 大改之后；首次上线 |
| **栏目发布** | 中（3-10s） | 改了一个栏目但其他没动 |
| **单篇发布** | 快（1-3s） | 改了某一篇文章 |

### 7.2 如何发布

- **文章详情页** → 右上角 "🚀 发布本篇"（仅显示该文章可发布的状态）
- **栏目页** → 右上角 "🚀 发布本栏目"  
- **发布页 `/admin/publish`** → 选站点 → "全站发布"

### 7.3 发布状态

| 状态 | 含义 |
|------|------|
| 排队中 (pending) | 还没开始构建 |
| 构建中 (building) | Astro 在生成静态 HTML |
| 成功 (success) | 已上线 |
| 失败 (failed) | 构建报错（点看日志） |
| 已取消 (cancelled) | 手动取消 |

构建时间 10-30s/站。**不需要盯进度**，完成会弹 toast + 顶栏小铃铛。

### 7.4 看发布日志

`/admin/publish` → 点任意 deployment → 看 "构建日志" 面板。

出错时通常能看到具体哪一行 HTML 有问题 / 哪个资源缺失。

### 7.5 回滚

历史发布都保留产物（默认 30 天）。回滚方法：

```
/admin/publish → 找到成功的历史版本 → 点 "回滚" 按钮
```

回滚是**软链切换**，秒级生效，不重新构建。

## 8. 媒体库

### 8.1 上传文件

`/admin/sites/{siteId}/media` 或栏目页 "媒体" tab：

- **拖拽**到上传区
- 或点 "上传" 选文件
- 支持：图片（PNG/JPG/WebP/SVG）/ 视频（MP4）/ 文档（PDF/DOCX/ZIP）

### 8.2 组织文件

- **文件夹**：点 "新建文件夹" 拖文件进去
- **重命名**：右键 → 重命名
- **删除**：右键 → 删除（已引用的会被警告）
- **搜索**：顶部搜索框按文件名搜

### 8.3 在文章里使用

编辑文章 → 点工具栏图片按钮 → 从媒体库选（或拖拽上传）

也可以直接在 HTML 模式粘 URL（指向 `https://media.example.com/...`）

### 8.4 文件命名建议

- 中文文件名 → 系统会自动转拼音 slug
- 推荐：`banner-home-2024.jpg` / `product-shoes-01.png`
- 避免：`IMG_20240315_xxx.jpg`（不语义）

## 9. 团队与权限

### 9.1 4 个内置角色

| 角色 | 权限 | 谁该用 |
|------|------|--------|
| **super_admin** | 全部权限 + 管用户/角色 | 平台管理员 |
| **site_owner** | 单站全部权限 | 站点负责人 |
| **editor** | 单站编辑内容，不能删他人/不能发布 | 内容创作者 |
| **viewer** | 单站只读 | 实习生 / 临时 |

### 9.2 邀请成员

1. **站点设置 → 成员** → "邀请成员"
2. 输入对方邮箱 + 选角色
3. 系统发邀请链接（24h 有效）
4. 对方点链接 → 注册/登录 → 自动加入

### 9.3 自定义角色（高级）

`/admin/roles` → "新建角色"：

- 命名（如 "内容审核员"）
- 勾选具体权限（60+ 权限粒度）
- 保存 → 邀请时可指定这个角色

### 9.4 权限矩阵速查

| 操作 | super_admin | site_owner | editor | viewer |
|------|------------|-----------|--------|--------|
| 创建站点 | ✅ | ❌ | ❌ | ❌ |
| 删除站点 | ✅ | ❌ | ❌ | ❌ |
| 创建栏目 | ✅ | ✅ | ✅ | ❌ |
| 写文章 | ✅ | ✅ | ✅ | ❌ |
| 送审/发布 | ✅ | ✅ | ❌ | ❌ |
| 邀请成员 | ✅ | ✅ | ❌ | ❌ |
| 看草稿 | ✅ | ✅ | ✅ | ❌ |

完整矩阵见 [10-权限矩阵.md](./10-权限矩阵.md)。

## 11. 常见问题 FAQ

### 11.1 内容相关

**Q: 文章保存了但没上线？**
A: 保存 ≠ 发布。点 "发布" 按钮才会上线。

**Q: 发布后前台看不到？**
A: 1) 检查是否域名 DNS 解析对 2) 等 30s 构建完成 3) 浏览器缓存试 Ctrl+Shift+R 强刷

**Q: 想撤销已发布的修改？**
A: 进文章 → "历史" → 选旧版本 → "回滚" → 再发布

**Q: 草稿能定时发布吗？**
A: 可以。点 "定时发布" → 选时间 → 系统到点自动发布

**Q: 文章能同时发到多个栏目吗？**
A: 可以。右侧栏栏目多选，最多 5 个

### 11.2 AI 相关

**Q: AI 一直转圈？**
A: 1) 检查网络 2) 顶部 NetworkStatus 是不是红色 banner 3) 等 30s 超时

**Q: AI 输出不准？**
A: 1) 换更强的模型（设置 → AI 模型 → GPT-4o / Claude）2) 提示词更具体

**Q: 怎么节省 AI token？**
A: 1) 选中文本而不是全文处理 2) 用本地 Ollama（无 API 费用但要 GPU）

**Q: AI 跑失败了能重跑吗？**
A: 可以。`/admin/ai/runs` → 选失败的 → "重新运行"

### 11.3 模板相关

**Q: 改模板样式没生效？**
A: 1) 改完要点 "发布" 才生效 2) 看浏览器缓存（强制刷新）

**Q: AI 改样式改坏了？**
A: 模板编辑有 "历史" 面板 → 选之前的版本 → "回滚"

**Q: 怎么复制别人的模板？**
A: 模板页 → 选模板 → "克隆" → 改名 → 改

**Q: 模板里能写 JS 吗？**
A: 可以，但要注意：
- 加 `<script>` 在 `<head>` 区
- 不要用 `document.write` 等老 API
- 发布前在浏览器开发者工具测一下

### 11.4 团队相关

**Q: 邀请邮件没收到？**
A: 1) 看垃圾邮件 2) 让 super admin 重新发 3) 检查邮箱拼写

**Q: 编辑者能看到别人草稿吗？**
A: 默认看不到，除非共享。具体权限看角色设置。

**Q: 怎么改自己的角色？**
A: 不能。只能 super_admin / site_owner 改成员角色。

**Q: 离职成员怎么移除？**
A: 站点设置 → 成员 → 找成员 → "移除"

### 11.5 性能相关

**Q: 后台加载慢？**
A: 1) 看 NetworkStatus 是不是断网 2) 列表筛选缩小范围 3) 清浏览器缓存

**Q: 发布很慢？**
A: 1) 改用"栏目发布"而非"全站发布" 2) 看部署日志是不是有错误循环

**Q: 媒体上传失败？**
A: 1) 文件 > 50MB 请用工具压缩 2) 看 MinIO 控制台 (`http://localhost:9001`) 3) 检查磁盘空间

### 11.6 安全相关

**Q: 怎么改密码？**
A: 右上角头像 → "设置" → "个人" → 改密码

**Q: 怎么开二次验证（2FA）？**
A: P5 计划中。目前靠强密码 + HTTPS + 短 token 有效期（15min）

**Q: 怀疑账号被盗？**
A: 立即改密码 + 联系 super_admin 强制登出

```
1. 看 Dashboard 数字（待审数 / 本月发布）

```

