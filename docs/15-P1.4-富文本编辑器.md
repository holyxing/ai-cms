## 设计选择

1. **body 存 HTML 字符串 (非 Tiptap JSON)**
   - 静态发布侧 SSG 用 unified/remark 解析, 已支持 HTML (docs/04a §4)
   - 旧 plain text 兼容: 加载时若不是 HTML 标签开头, 自动 wrap `<p>`
   - 避免在 DB 加新列或做 JSON↔HTML 双向转换

2. **动态加载**
   - `const BlockEditor = lazy(() => import('@/components/editor/BlockEditor'))`
   - 主包不变, 仅访问 ContentDetail 时拉 Tiptap (主包 +4 个 extension ≈ 200KB gzip)

3. **toolbar 简化**
   - 6 个 block: heading(1/2/3) / bulletList / orderedList / blockquote / codeBlock
   - 4 个 mark: bold / italic / strike / code
   - 1 个 mark 扩展: link (弹窗输入 URL)
   - undo/redo
   - **不做**: 表格 / 媒体上传 / markdown 粘贴 / 协作 (V2+)

4. **样式**
   - 用 `@tailwindcss/typography` 的 `prose` 基础类
   - 块级元素 (h1/h2/h3/p/ul/ol/blockquote/pre/code) 走项目 token, 不写死颜色
   - 设计系统一致: 圆角 8px, 边框 1px, blue-600 激活态
