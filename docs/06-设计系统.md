# 06 · 设计系统（Design System）

> **本文档是 AI-CMS 所有 UI 的唯一标准**。任何页面、任何组件、任何 agent 写 UI 之前必读。
> 违反本文档的设计 = bug。

---

## 0. 核心理念（一句话）

**白底科技蓝 · 紧凑信息密度 · 文字主导 · 抽象动图点缀 · 永远不"AI 装饰堆砌"**

参考对象：Linear / Vercel / 飞书 / 钉钉 / Plane.so / Cal.com

---

## 1. 色彩 Token

### 1.1 基础色（不可改）

```css
/* 主色系: 科技蓝（产品统一识别色） */
--primary:          221 83% 53%;  /* #2563eb 蓝色按钮/链接/激活态 */
--primary-foreground: 0 0% 100%;

/* 中性色: 灰阶 */
--background:        0 0% 100%;
--foreground:        222 47% 11%;  /* #0f172a 正文, **不要纯黑** */
--secondary:         220 14% 96%;  /* #f1f5f9 次级背景/hover */
--muted:             220 14% 96%;
--muted-foreground:  220 9% 46%;   /* #64748b 副文字/标签 */
--border:            220 13% 91%;  /* #e2e8f0 分割线/边框 */
--input:             220 13% 91%;
--ring:              221 83% 53%;  /* 聚焦环 = 主色 */
--destructive:       0 72% 51%;    /* #dc2626 危险操作 */
--radius:            6px;          /* 圆角全局 6px, 不用 12/16 */
```

### 1.2 强调色（仅用于状态点/分类标签/图标，**不作主色背景**）

```css
--accent-blue:    221 83% 53%;  /* #2563eb */
--accent-emerald: 160 84% 39%;  /* #10b981 成功 */
--accent-amber:   38 92% 50%;   /* #f59e0b 警告 */
--accent-purple:  262 83% 58%;  /* #a855f7 */
--accent-rose:    351 89% 60%;  /* #e11d48 */
--accent-cyan:    187 95% 43%;  /* #06b6d4 */
```

**使用规则**：
- 蓝色 = 主操作（按钮、链接、激活状态）
- emerald = 成功 / 在线 / 已完成
- amber = 警告 / 待审 / 注意
- rose/red = 错误 / 失败 / 删除
- cyan / purple / 其他 = 视觉点缀（次要数据、分类）
- **不要混搭**：一组数据内最多 2-3 个色，超出就是杂耍

### 1.3 禁用色

- ❌ **纯黑**（`#000`）— 永远不用于文字或背景
- ❌ **深紫深绿大色块背景**— 不用作 Hero
- ❌ **彩虹渐变**（5 色以上渐变）
- ❌ **大色块背景**（除主色按钮外）

## 2. 字号 Scale（**8 级，禁止越界**）

| 级别 | 类名 | 像素 | 用途 |
|---|---|---|---|
| xs | `text-[10px]` | 10 | 仅用于版权 / 版本号 |
| micro | `text-[11px]` | 11 | 标签、Badge、状态点说明 |
| sm-mini | `text-xs` | 12 | 次要信息、辅助说明 |
| sm | `text-sm` | 14 | **默认正文、按钮、表单** |
| base | `text-base` | 16 | 卡片标题、Modal 标题 |
| lg | `text-lg` | 18 | 页面 section 标题 |
| xl | `text-xl` | 20 | 页面 H1（Dashboard "概览"）|
| 2xl | `text-2xl` | 24 | 数字、统计值 |
| display | `text-[40px]` | 40 | **仅 Login 主标题**（全局唯一）|

**字重**：
- `font-medium` (500) = 卡片标题、按钮、强调
- `font-semibold` (600) = 页面 H1、大数字
- `font-normal` (400) = 正文（默认）
- **不要用 bold (700+)** — 数字优先用字号区分，不用字重

**字距**：
- `tracking-[-0.02em]` = 标题（紧凑）
- `tracking-[0.2em]` = uppercase 小标签（AI · CMS · SSG）

## 3. 间距（**8px 网格**）

| Token | 类 | px | 用途 |
|---|---|---|---|
| 0.5 | `gap-0.5` | 2 | 图标和文字之间 |
| 1 | `gap-1` | 4 | 极小间距 |
| 1.5 | `gap-1.5` | 6 | 标签内边距 |
| 2 | `gap-2` | 8 | 控件之间、表单行间距 |
| 2.5 | `gap-2.5` | 10 | 列表行内元素 |
| 3 | `gap-3` | 12 | 卡片内元素 |
| 4 | `gap-4` | 16 | 卡片间距 |
| 5 | `gap-5` | 20 | Section 间距 |
| 6 | `gap-6` | 24 | 区块间距 |
| 8 | `gap-8` | 32 | 页面 section |
| 10 | `gap-10` | 40 | 大模块 |
| 12 | `gap-12` | 48 | Hero 间距 |
| 16 | `gap-16` | 64 | 页面 hero |

**严禁** 7/9/11/13/14/15 这种非 8 倍数（Tailwind 默认就有这些，但要主动避免）。

## 4. 圆角

| 用途 | 类 | px |
|---|---|---|
| 按钮、输入框、Badge | `rounded-md` | 6 |
| 卡片、Modal | `rounded-lg` | 8 |
| 头像、状态点 | `rounded-full` | 50% |
| 极小元素（数字 badge）| `rounded` | 4 |

**禁止**：`rounded-2xl`(16px) / `rounded-3xl`(24px) / `rounded-[20px]`（任何自定义大圆角）

## 5. 阴影

| 用途 | 类 |
|---|---|
| 默认 | 无阴影（用 1px 边框代替）|
| 卡片 hover | `shadow-sm` |
| Modal / Popover | `shadow-md` |
| 拖拽中 | `shadow-lg` |
| **禁用** | `shadow-xl` / `shadow-2xl` / 任何彩色阴影 / `drop-shadow-*` |

## 6. 核心组件规范

### 6.1 Button

```tsx
// 主按钮 (蓝色)
<Button className="h-8 text-xs">操作</Button>     // 紧凑 (列表行)
<Button className="h-9 text-sm">登录</Button>     // 标准 (表单)

// 文字按钮
<Button variant="ghost" className="h-6 text-[11px]">次要操作</Button>

// 图标按钮
<Button variant="ghost" size="icon" className="h-8 w-8">
  <Search className="h-4 w-4" />
</Button>
```

**禁用**：
- ❌ 渐变背景（`bg-gradient-to-r from-blue-...`）
- ❌ 发光效果（`shadow-[0_0_30px]`）
- ❌ 大圆角按钮（`rounded-full` 用于 icon-only OK，否则禁止）

### 6.2 Card

```tsx
<Card>
  <div className="border-b px-5 py-3">
    <h2 className="text-sm font-semibold">标题</h2>
  </div>
  <div className="p-5">内容</div>
</Card>
```

- 圆角 `rounded-lg` (8px)
- 边框 `border` (1px 灰)
- **不加阴影**（靠边框区分层次）
- 内部 section 用 `border-b` 分隔

### 6.3 Badge

**7 个变体**（禁加其他）：
- `default` - 灰底
- `outline` - 灰边
- `muted` - 透明 + 灰字
- `success` - 浅绿
- `warning` - 浅黄
- `info` - 浅蓝
- `purple` - 浅紫

**样式统一**：`rounded-md px-1.5 text-[11px] font-medium leading-5`

**禁止**：渐变 Badge、emoji Badge、彩色实心 Badge。

### 6.4 Input

```tsx
<div className="space-y-1.5">
  <Label className="text-xs font-medium">邮箱</Label>
  <div className="relative">
    <Icon className="absolute left-2.5 top-1/2 h-3.5 w-3.5 -translate-y-1/2 text-muted-foreground" />
    <Input className="h-9 pl-8 text-sm" />
  </div>
</div>
```

- 高度 `h-9` (36px) 标准 / `h-8` (32px) 紧凑
- 字号 `text-sm` (14px)
- 左边图标 `h-3.5 w-3.5`
- **不加 focus 时的彩色边框动画**（默认即可）

### 6.5 Avatar

```tsx
<Avatar name={user.name} size="sm" />  // 24px
<Avatar name={user.name} size="md" />  // 32px
<Avatar name={user.name} size="lg" />  // 40px
```

- 初始字母（中文取首字）
- 颜色 = 名字哈希 → 35% saturation（**不饱和**）
- `rounded-full`

### 6.6 EmptyState（必须有，用于空数据）

```tsx
<EmptyState
  icon={FileText}
  title="还没有文章"
  description="从一篇 AI 协助起稿的文章开始"
  action={<Button>新建文章</Button>}
/>
```

## 7. 布局标准

### 7.1 后台通用布局（AppLayout）

```
┌──────┬─────────────────────────────────┐
│      │  [面包屑]      [搜索][通知]     │  ← 顶栏 56px
│  侧  ├─────────────────────────────────┤
│  边  │                                  │
│  栏  │         工作区 (Outlet)         │
│  224 │         px-6 py-6 / lg:px-8     │
│  px  │         (NOT max-w-6xl)         │
│      │                                  │
└──────┴─────────────────────────────────┘
```

**关键**：
- 工作区**铺满屏幕**，不用 `max-w-6xl`（除非特殊内容页）
- 工作区 padding `px-6 py-6`（移动端）/ `lg:px-8 lg:py-8`（桌面）
- 侧边栏固定 `w-56` (224px)
- 顶栏固定 `h-14` (56px)

### 7.2 数字行（**4 列 gap-px border 共享**）

```tsx
<section className="mb-6 grid grid-cols-2 gap-px overflow-hidden rounded-lg border bg-border lg:grid-cols-4">
  {stats.map(s => (
    <div key={s.label} className="bg-background p-4">
      <div className="flex items-center justify-between">
        <div className="text-xs font-medium text-muted-foreground">{s.label}</div>
        <div className="flex h-7 w-7 items-center justify-center rounded-md bg-blue-50">
          <Icon className="h-3.5 w-3.5 text-blue-600" />
        </div>
      </div>
      <div className="mt-3 flex items-baseline gap-1">
        <span className="text-2xl font-semibold tabular-nums">{s.value}</span>
        {s.unit && <span className="text-sm text-muted-foreground">{s.unit}</span>}
      </div>
    </div>
  ))}
</section>
```

**关键**：
- `gap-px + bg-border` + 内部 `bg-background` → 共享 1px 边框（视觉连成一片）
- 数字 `text-2xl font-semibold tabular-nums`
- 标签 `text-xs font-medium text-muted-foreground`
- 图标块 `h-7 w-7 rounded-md bg-{color}-50 text-{color}-600`

### 7.3 卡片网格

- 卡片间 `gap-6` (24px)
- 卡片内 padding `p-4` (16px) 标准 / `p-5` (20px) 宽松
- 卡片内 section 用 `border-b` 分割

### 7.4 表格

- 行高 36-40px (`h-9` / `h-10`)
- 单元格 padding `px-3` / `px-4`
- 表头 `text-[11px] font-medium text-muted-foreground uppercase tracking-wider`
- hover `row-hover` (浅灰)

## 12. 图标规范

- 库：**lucide-react**（**唯一**）
- 默认 stroke-width `1.75`，激活 `2`
- 尺寸：
  - `h-3 w-3` (12px) - 极小（如退出按钮内）
  - `h-3.5 w-3.5` (14px) - 默认（导航、列表、按钮内）
  - `h-4 w-4` (16px) - 中等（顶栏、表头）
  - `h-5 w-5` (20px) - 大（空状态、Modal 标题）

**禁止**：
- ❌ emoji 当图标（用 lucide 替代）
- ❌ 彩色图标（保持 `currentColor`）
- ❌ 自定义 SVG（除非必要）

## 13. 错误示例（**禁止**）

| 错误做法 | 为什么 |
|---|---|
| 渐变背景 `bg-gradient-to-r from-purple-500 to-pink-500` | 太花哨，AI 感 |
| `rounded-2xl` (16px) 圆角 | 太卡通，不专业 |
| `shadow-2xl` 大阴影 | 浮夸 |
| 5 个图标用 5 种不同颜色 | 视觉混乱 |
| 主标题用 `bg-gradient-to-r from-blue-... to-pink-...` 5 色 | 彩虹 |
| `text-[60px]` 巨号字 | 除 Login 外不用 |
| emoji 🔥🚀✨ 当功能图标 | 不专业 |
| 黑底白字 Hero | 太重 |
| 圆环图、雷达图、3D 图 | 不实用 |
| Tailwind 之外的 `style={{ ... }}`（除动画）| 难维护 |
| 自定义颜色 `#abcdef` | 必须用 token |

## 15. Dark 主题 (P4.1 / 2026-06-19)

### 15.1 切换方式

**3 档**: 浅色 / 深色 / 跟系统, **默认 `跟系统`**.

- **入口**: AppLayout 顶栏 Sun/Moon 图标 + 下拉 (位置: `<GlobalSearchBox />` 之后, UserMenu 之前)
- **持久化**: `useAppearanceStore.darkMode` (Zustand + localStorage)
- **DOM 激活**: `<html data-theme-mode="light|dark">`, 跟 `index.css` 的 `:root[data-theme-mode="dark"]` 选择器联动
- **系统跟随**: 监听 `prefers-color-scheme` media query, 变化时实时切
- **不用 Tailwind `darkMode: 'media'`**: 项目用 class/data-attribute 模式 (P3.6.2 教训, 默认 media 模式系统一深色就全乱)

### 15.2 色板 Token (HSL)

色值已写进 `frontend/src/index.css` (`:root` 是 light, `:root[data-theme-mode="dark"]` 是 dark), 这里列规范.

| token | light | dark | 用途 |
|---|---|---|---|
| `--background` | `0 0% 100%` | `222 47% 7%` | 页底 |
| `--foreground` | `222 47% 11%` | `210 40% 98%` | 主文字 |
| `--card` | `0 0% 100%` | `222 47% 9%` | 卡片底 |
| `--card-foreground` | `222 47% 11%` | `210 40% 98%` | 卡片文字 |
| `--popover` | `0 0% 100%` | `222 47% 9%` | 弹层 (Dialog/Menu/Tooltip/Popover) |
| `--popover-foreground` | `222 47% 11%` | `210 40% 98%` | 弹层文字 |
| `--secondary` | `220 14% 96%` | `217 33% 14%` | 次级容器 / hover |
| `--secondary-foreground` | `222 47% 11%` | `210 40% 98%` | 次级文字 |
| `--muted` | `220 14% 96%` | `217 33% 14%` | 弱化背景 |
| `--muted-foreground` | `220 9% 46%` | `215 20% 65%` | 弱化文字 (副标题/标签) |
| `--accent` | `220 14% 96%` | `217 33% 14%` | hover 高亮背景 |
| `--accent-foreground` | `222 47% 11%` | `210 40% 98%` | hover 高亮文字 |
| `--border` | `220 13% 91%` | `217 33% 17%` | 描边 / 分割线 |

| `--ring` | `221 83% 53%` | `221 83% 53%` | 焦点环 (= 主色) |
| `--primary` | `221 83% 53%` | `221 83% 53%` | **主色保持品牌色, 两模式相同** |
| `--destructive` | `0 72% 51%` | `0 72% 51%` | **危险红保持, 两模式相同** |
| `--accent-blue/emerald/amber/...` | (略) | **提亮 5-10%** | 状态点 (dark 下需更亮才清晰) |

### 15.3 对比度规范 (WCAG AA)

| 关系 | 要求 |
|---|---|
| 主文字 vs 背景 | ≥ **4.5:1** |
| 次级文字 vs 背景 | ≥ **4.5:1** |
| 弱化文字 vs 背景 | ≥ **3:1** (Large only) |
| ❌ 不允许 | dark 模式用 `--muted-foreground` (`215 20% 65%`) 写正文 |

### 15.4 禁止的写法

| ❌ 错 | ✅ 对 | 原因 |
|---|---|---|
| `bg-white` / `bg-white/xx` | `bg-card` / `bg-popover` / `bg-background` | dark 模式全废 (P3.6.1 治标的根源) |
| `text-zinc-xxx` / `bg-slate-xxx` / `bg-gray-xxx` | `text-foreground` / `text-muted-foreground` | 同上 |
| `dark:bg-xxx` (Tailwind `dark:` 前缀) | 不写 `dark:`, 改 token | 项目用 `data-theme-mode` 模式, 不用 Tailwind `darkMode: 'media'` |
| `style={{ background: '#fff' }}` | token | 硬编码 |
| `[&.dark]:bg-xxx` | 走 token | 同上 |
| `prefers-color-scheme` 在组件里写 | 只在 `stores/appearance.ts` 用 | 切档逻辑只走 store, 不分散 |
