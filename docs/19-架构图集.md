# 19. 架构图集 (P3.9.5+ 截至 2026-06-12)

> 本文档以 mermaid 形式汇总产品/技术/数据库/血线/序列图。  
> 5 张图，对应 holy 反馈点：文档导入 + 静态发布图片真静态化 + LLMRequest 修。  
> **核心变化**（P3.9.4 → P3.9.5）：
> 1. **新增 ai_run_steps / ai_usage_daily / media_tags / media_tag_links / site_assets** 等 P3 表
> 2. **ai_runs.task_type** 18 个值（含 3 个 import_*）
> 3. **静态发布产物**改为 `public/assets/{basename}.png` 相对路径，**离线可看**

## 5. 产品流程图（多泳道序列图）

定位：**文档导入**完整流程，6 泳道 — Browser / Frontend / FastAPI / Worker / MinIO / LLM。

```mermaid
sequenceDiagram
    autonumber
    actor U as 运营
    participant FE as 前端<br/>(React)
    participant API as FastAPI
    participant MINIO as MinIO
    participant WK as Celery Worker
    participant LLM as LLM Provider

    Note over U,LLM: 场景：用户点"导入 Word 文档"

    U->>FE: 点"导入 Word 文档"按钮
    FE->>FE: 隐藏 file input.click()
    U->>FE: 选 test.docx
    FE->>API: POST /media/upload (multipart)
    API->>MINIO: boto3 put_object
    MINIO-->>API: presigned URL
    API-->>FE: { url: "/media/sites/.../docx?X-Amz-..." }
    
    FE->>API: POST /ai/tasks/import_docx/start<br/>{ file_url, apply_layout: true }
    API->>API: 写 ai_runs (status=pending)
    API-->>FE: 202 { run_id, stream_url }
    API->>WK: enqueue execute_ai_run(run_id)
    
    FE->>API: GET /ai/runs/{id}/stream (SSE)
    
    par Worker 执行
        WK->>API: 查 ai_runs
        WK->>WK: 写 ai_run_steps (validate, order=1)
        WK->>MINIO: boto3 get_object(/media/.../docx)
        MINIO-->>WK: file_bytes (36805)
        WK->>WK: python-docx 解析段落 + 提图
        WK->>MINIO: 上传 base64 图 → /media/.../png
        WK->>WK: 写 ai_run_steps (generate, order=2)
        
        opt apply_layout = true
            WK->>LLM: stream(messages, model=qwen2.5)
            LLM-->>WK: chunk delta (排版后 HTML)
            Note over WK,LLM: 累计 prompt_tokens=289<br/>completion_tokens=100<br/>cost=$0.001089
        end
        
        WK->>API: 写 content_versions (HTML 主体)
        WK->>API: 写 ai_runs (status=success)
    and 前端 SSE 推送
        API-->>FE: SSE event: step=validate
        API-->>FE: SSE event: step=generate + delta
        API-->>FE: SSE event: step=save
        API-->>FE: SSE event: done
    end
    
    FE->>FE: 显示 diff 对话框
    U->>FE: 点"接受"
    FE->>API: POST /ai/runs/{id}/accept
    API->>API: 写 content_versions 终态
    API-->>FE: 200
    FE->>U: Toast: "已应用"
```

**6 泳道**：
| 泳道 | 角色 | 关键动作 |
|---|---|---|
| 1 | 运营 | 选文件、点接受 |
| 2 | 前端 React | 隐藏 file input、调用 API、监听 SSE |
| 3 | FastAPI | multipart 上传、创建 ai_runs、enqueue、推 SSE |
| 4 | MinIO | put_object (上传)、get_object (worker 拉) |
| 5 | Celery Worker | 解析、boto3 拉、写 ai_run_steps、调 LLM stream |
| 6 | LLM Provider | 流式返排版 HTML |

**关键改进**（P3.9.5 相对 P3.9.4）：
- ✅ **`apply_layout` 真正生效**（`provider.stream` 接 token/cost）
- ✅ **图片真静态化**（发布时 `_inline_content_media` 改 `<img src>` 为 `assets/` 相对路径）

## 6. 静态发布序列图（多泳道）

定位：发布时的完整时序，5 泳道 — Browser / API / Worker / MinIO / Nginx。

```mermaid
sequenceDiagram
    autonumber
    actor U as 运营
    participant FE as 前端
    participant API as FastAPI
    participant WK as Worker
    participant MINIO as MinIO
    participant NGX as Nginx

    U->>FE: 点"发布"按钮
    FE->>API: POST /sites/{id}/publish { force: true }
    API->>API: 写 deployments (status=pending)
    API-->>FE: 202 { deployment_id }
    API->>WK: enqueue run_publish
    
    FE->>API: GET /publish/jobs/{id} (轮询)
    
    WK->>WK: 拉 site / theme / contents
    WK->>WK: build_site() 渲染 pages
    WK->>WK: DiskWriter.write_all() 写 public/
    Note over WK: 12 pages, 14873 bytes
    
    WK->>WK: _inline_content_media(public/)
    WK->>MINIO: boto3 get_object(sites/.../1zoYyWyACU8.png)
    MINIO-->>WK: 81 bytes (PNG 100x100)
    WK->>WK: 写 public/assets/1zoYyWyACU8.png
    WK->>WK: 改写所有 *.html 的 <img src>
    Note over WK: downloaded=1 reused=0<br/>unique_keys=1 rewrites=2
    
    WK->>WK: _copy_assets_to_public(site_assets)
    Note over WK: copied 2/9
    
    WK->>API: 写 deployments (status=success)
    API-->>FE: 200 { status: success, duration: 86ms }
    
    U->>NGX: 访客访问 /sites/{slug}/
    NGX-->>U: 静态 HTML + assets/*.png
    Note over NGX,U: 离线可看, 不依赖 MinIO
```

**关键改进点**：
- P3.9.4 之前：`<img src="/media/sites/.../foo.png?X-Amz-...">` → 必须经 nginx → MinIO 反代才能渲染
- P3.9.5 之后：`<img src="assets/foo.png">` → nginx 直接吐文件，**离线可看**
