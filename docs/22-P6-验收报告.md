## 7. 决策记录 (供后续)

1. **localStorage 优先**: dashboard 布局 (P6.5) + 站点 pin (P6.4) 不走后端, 避免新建 model
2. **批量 per-id 不中断**: 即使 50 个里有 3 个失败, 其余 47 个继续, 后端返 `{results, succeeded, failed}` 让前端分别 toast
3. **跨栏 drop 拒收** (P6.5): 用 `data: { column }` 透传 + `onDragOver` 检查, 实现简单 + 视觉不破坏
4. **dnd-kit 而非 react-dnd**: P6.5 选了 dnd-kit, 因为 (a) 现代维护 (b) 不需要 HTML5 backend (c) 与 React 18 并发模式兼容
5. **FastLoading 200ms 延迟**: 避免网络快时 (≤200ms) 出现闪烁 skeleton, 业内通用阈值
6. **Notifications 用 zustand persist**: 与 theme/dashboard layout 同栈, 不引 Redux/Recoil
7. **BatchActionBar 浮底**: 跟行业一致 (Notion / Linear / GitHub), 不占 toolbar 高度
8. **P6 跳过项**: #5/#9/#10/#15/#20/#24 — 都是"未来有需要再加", 不预先铺垫
