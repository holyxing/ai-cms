# 04 · 数据模型（Database Schema）

> **P1 启动前必读**。18 张表完整 DDL + 索引 + 关系 + 决策说明。
> 与 `docs/07-开发注意事项.md` §4 配合使用。

---

## 0. 设计原则

1. **软删除统一**：业务表用 `deleted_at TIMESTAMPTZ`（不是 `is_deleted` boolean），`NULL` = 未删除，30 天后 Celery 清理
2. **所有业务表必备字段**：
   - `id BIGSERIAL PRIMARY KEY`
   - `created_at TIMESTAMPTZ DEFAULT NOW()`
   - `updated_at TIMESTAMPTZ DEFAULT NOW()`（trigger 自动更新）
   - `deleted_at TIMESTAMPTZ DEFAULT NULL`
3. **多租户隔离**（严重：所有查询必须强制带 site_id）：
   - 启用 PostgreSQL **Row-Level Security (RLS)**
   - ORM 层 `TenantScoped` 抽象基类
4. **金额/计数用 BIGINT**：避免 32 位溢出
5. **JSON 字段**：可变的元数据用 `JSONB`（带 GIN 索引）
6. **时间戳统一 UTC**（应用层转本地时区）

## 3. P1 表（10 张完整 DDL）

### 3.1 `sites` 站点

```sql
CREATE TABLE sites (
  id              BIGSERIAL PRIMARY KEY,
  slug            VARCHAR(64) NOT NULL UNIQUE,     -- URL 标识, 全站唯一
  name            VARCHAR(128) NOT NULL,
  description     TEXT,
  logo_url        TEXT,
  owner_id        BIGINT NOT NULL REFERENCES users(id) ON DELETE RESTRICT,
  status          VARCHAR(20) NOT NULL DEFAULT 'active',  -- active | archived
  settings        JSONB DEFAULT '{}'::jsonb,      -- 站点级设置 (SEO/分析等)
  created_at      TIMESTAMPTZ NOT NULL DEFAULT NOW(),
  updated_at      TIMESTAMPTZ NOT NULL DEFAULT NOW(),
  deleted_at      TIMESTAMPTZ DEFAULT NULL
);

CREATE INDEX idx_sites_owner ON sites(owner_id) WHERE deleted_at IS NULL;
CREATE INDEX idx_sites_status ON sites(status) WHERE deleted_at IS NULL;
```

### 3.2 `site_domains` 站点域名

```sql
CREATE TABLE site_domains (
  id              BIGSERIAL PRIMARY KEY,
  site_id         BIGINT NOT NULL REFERENCES sites(id) ON DELETE CASCADE,
  domain          VARCHAR(255) NOT NULL UNIQUE,    -- example.com
  type            VARCHAR(20) NOT NULL DEFAULT 'primary',  -- primary | alias | preview
  ssl_status      VARCHAR(20) NOT NULL DEFAULT 'pending',  -- pending | active | failed
  verified_at     TIMESTAMPTZ,
  created_at      TIMESTAMPTZ NOT NULL DEFAULT NOW(),
  updated_at      TIMESTAMPTZ NOT NULL DEFAULT NOW(),
  deleted_at      TIMESTAMPTZ DEFAULT NULL
);

CREATE INDEX idx_site_domains_site ON site_domains(site_id) WHERE deleted_at IS NULL;
```

### 3.5 `taxonomies` 栏目（树）

```sql
CREATE TABLE taxonomies (
  id              BIGSERIAL PRIMARY KEY,
  site_id         BIGINT NOT NULL REFERENCES sites(id) ON DELETE CASCADE,
  parent_id       BIGINT REFERENCES taxonomies(id) ON DELETE CASCADE,  -- 父栏目
  name            VARCHAR(128) NOT NULL,
  slug            VARCHAR(128) NOT NULL,
  type            VARCHAR(20) NOT NULL,  -- category | tag
  path            TEXT NOT NULL,         -- 物化路径 "/1/3/7/"
  description     TEXT,
  order_num       INTEGER NOT NULL DEFAULT 0,  -- 同级排序
  seo             JSONB DEFAULT '{}'::jsonb,  -- {title, description, keywords}
  created_at      TIMESTAMPTZ NOT NULL DEFAULT NOW(),
  updated_at      TIMESTAMPTZ NOT NULL DEFAULT NOW(),
  deleted_at      TIMESTAMPTZ DEFAULT NULL,
  UNIQUE (site_id, slug, type)
);

CREATE INDEX idx_taxonomies_site ON taxonomies(site_id) WHERE deleted_at IS NULL;
CREATE INDEX idx_taxonomies_parent ON taxonomies(parent_id) WHERE deleted_at IS NULL;
CREATE INDEX idx_taxonomies_path ON taxonomies(path) WHERE deleted_at IS NULL;  -- 子树查询
```

### 3.6 `contents` 内容

```sql
CREATE TABLE contents (
  id              BIGSERIAL PRIMARY KEY,
  site_id         BIGINT NOT NULL REFERENCES sites(id) ON DELETE CASCADE,
  author_id       BIGINT NOT NULL REFERENCES users(id) ON DELETE RESTRICT,
  title           VARCHAR(255) NOT NULL,
  slug            VARCHAR(255) NOT NULL,
  excerpt         TEXT,                  -- 摘要, 用于列表/SEO

  scheduled_at    TIMESTAMPTZ,           -- 计划发布时间

  locked_by       BIGINT REFERENCES users(id),  -- 协作锁
  locked_at       TIMESTAMPTZ,           -- 5 分钟自动过期
  cover_image_id  BIGINT REFERENCES media(id),  -- 封面图
  search_vector   tsvector,              -- PG 全文检索
  metadata        JSONB DEFAULT '{}'::jsonb,    -- 标签/分类/自定义字段
  view_count      BIGINT NOT NULL DEFAULT 0,
  created_at      TIMESTAMPTZ NOT NULL DEFAULT NOW(),
  updated_at      TIMESTAMPTZ NOT NULL DEFAULT NOW(),
  deleted_at      TIMESTAMPTZ DEFAULT NULL,

CREATE INDEX idx_contents_site_status ON contents(site_id, status) WHERE deleted_at IS NULL;
CREATE INDEX idx_contents_author ON contents(author_id) WHERE deleted_at IS NULL;
CREATE INDEX idx_contents_search ON contents USING GIN(search_vector) WHERE deleted_at IS NULL;
```

## 6. 多租户隔离实现（严重）

### 6.1 PostgreSQL RLS

```sql
-- 启用 RLS 的表
ALTER TABLE contents ENABLE ROW LEVEL SECURITY;
ALTER TABLE media ENABLE ROW LEVEL SECURITY;
-- ... 其他含 site_id 的表

-- 策略: 用户只能访问自己有权访问的站点数据
CREATE POLICY tenant_isolation_contents ON contents
  USING (
    site_id IN (
      SELECT site_id FROM site_members
      WHERE user_id = current_setting('app.current_user_id')::BIGINT
        AND deleted_at IS NULL
    )
    OR
    EXISTS (
      SELECT 1 FROM users
      WHERE id = current_setting('app.current_user_id')::BIGINT
        AND is_super_admin = TRUE
    )
);

-- API 每次请求前 set:
SET app.current_user_id = '123';
```

### 6.2 应用层 BaseQuery

```python
# backend/app/db/base.py
class TenantScoped:
    @classmethod
    def query(cls, db, user):
        q = db.query(cls)
        if user.is_super_admin:
            return q
        accessible = db.query(SiteMember.site_id).filter(
            SiteMember.user_id == user.id,
            SiteMember.deleted_at.is_(None)
        ).subquery()
        return q.filter(cls.site_id.in_(accessible))
```

## 7. 关键决策（**不可改**）

| 决策 | 原因 |
|---|---|
| 一文**一站** + **多栏目**（N:N）| 一文多站复杂度太高, 多栏目足够覆盖 95% 场景 |
| 栏目树 = 邻接表 + 物化路径 | 子树查询快 (`LIKE '/1/3/%'`) + 移动节点便宜 |
| 软删除统一用 `deleted_at` | 30 天回收站, Celery 定期清理 |
| **content_versions 永存** | 审计/回滚, 不删 |
| 媒体去重用 `md5 UNIQUE` | 同一图片上传两次 = 同一条记录 |
| 主题 = tokens + Astro 模板 | AI 改主题只能改 tokens, 不能改 HTML |
| 部署 = 全量重建（不在前端 SSG）| 简单, P4 再优化增量 |
| AI 调用**后端代理** | Key 不暴露前端, 限流/记账在后端 |
| AI Key Fernet 加密 | 用 `BACKEND_SECRET` 加密, 密钥不存 DB |
| 审计日志**只增不改** | revoke UPDATE/DELETE, 定期归档冷存 |

```
  │
  ├──1──* api_keys (加密)
```

## 10. 索引策略

- **业务表高频查询字段**（如 `site_id + status`）建复合索引
- **GIN 索引**：JSONB、tsvector
- **部分索引**：`WHERE deleted_at IS NULL` 让索引更小更快
- **外键** 全部建索引（PG 默认不建，必须显式建）
- **不要**在 boolean / enum / 小 cardinality 字段建索引

## 12. 备份/恢复（P4 必做，生产前必须）

```bash
# 每日备份
docker exec ai-cms-postgres pg_dump -U ai_cms ai_cms | gzip > /backup/ai_cms_$(date +%F).sql.gz

mc cp /backup/ai_cms_*.sql.gz ai-cms/backups/db/

gunzip -c /backup/ai_cms_2026-06-04.sql.gz | docker exec -i ai-cms-postgres psql -U ai_cms ai_cms
```
