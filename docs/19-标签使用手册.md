# 标签使用手册 — AI-CMS Layout 系统 (HY_ 占位符)

> **目标读者**：模板编辑者（产品 / 设计 / 前端）  
> **版本**：v1.0 (2026-06-10)  
> **配套文档**：[18-布局系统与标签占位符.md](./18-布局系统与标签占位符.md)（系统设计） · [06-设计系统.md](./06-设计系统.md)（UI 规范）  
> **在线试玩**：admin 后台 → 「模板」菜单 → 任意 layout → 编辑

---

## 0. 一句话入门

在 layout HTML 里用 `<HY_XXX/>` 自闭合标签告诉系统"这里要换成实际内容"。`HY_*` 系统按当前页面（站点首页 / 栏目页 / 详情页）自动注入对应数据。**所有标签 `HY_` 前缀** — 跟 HTML 标签完全隔离。

```html
<h1><HY_SITE_NAME/></h1>
<p><HY_CONTENT_TITLE/></p>
```

渲染成：

```html
<h1>霍因科技</h1>
<p>海石 · 数据安全治理平台</p>
```

**关键约定**：
- 自闭合用 `<HY_XXX/>`（推荐）或 `<HY_XXX></HY_XXX>`（等价）
- 容器必须配对：`<HY_CONTENTS>...</HY_CONTENTS>`
- 自定义属性一律 `_` 前缀（`_include` `_match` `_limit`），防 HTML 原生属性冲突
- 标签名**大写**，下划线分词，不支持驼峰

## 4. 资源标签（3 个）— 站点 CSS/JS 装载

**核心规则**：资源在 admin → 「站点资源」上传到 `site_assets`，发布时同步到 `public/{site_slug}/assets/{category}/{name}`，模板用以下标签引入。

### 4.1 `HY_SITE_CSS` / `HY_SITE_JS` — 一键引入目录

```html
<!-- 引入 css/ 下所有资源（按上传顺序） -->
<HY_SITE_CSS />

<!-- 只引入白名单（逗号分隔） -->
<HY_SITE_CSS _include="style-merged-2.css,news-list.css" />

<!-- 排除黑名单 -->
<HY_SITE_CSS _exclude="old.css,debug.css" />
```

**行为**：
- 输出多行 `<link rel="stylesheet" href="../assets/...">`（JS 则是 `<script src="...">`）
- `_include` 和 `_exclude` 互斥，优先 `_include`
- 自动处理相对路径（首页用 `assets/...`，栏目子页用 `../assets/...`）
- 资源未上传 → 该行**不输出**（不报 404）

**典型 site layout head**：
```html
<HY_SITE_CSS />                          <!-- 站点级 token + 布局 -->
<HY_SITE_CSS _include="style-merged-2.css" />  <!-- 业务 CSS (合并) -->
<HY_SITE_JS _include="script-merged.js" />     <!-- 业务 JS (合并) -->
```

### 4.2 `HY_ASSET_URL _name="..."` — 单个资源 URL

```html
<!-- 推荐: 显式 _name 属性 -->
<link rel="stylesheet" href="<HY_ASSET_URL _name="style.css" />">

<!-- 兼容: 假装属性 -->
<link rel="stylesheet" href="<HY_ASSET_URL style.css />">

<!-- 独立占位 (在 <body> 中显示 URL) -->
<span>Logo: <HY_ASSET_URL _name="logo.svg" /></span>
```

**用途**：当 `HY_SITE_CSS` 不够灵活、需要**控制 link 标签属性**（如 `media`、`crossorigin`、`integrity`）时，用 `HY_ASSET_URL` 配合手写 link 标签。

## 5. 页面标签（4 个）— `HY_PAGE_*`

用于 **site scope layout** 的 `<head>` 区。**优先级**：详情页 (`content`) > 栏目页 (`category`) > 兑底 (`site`)。

| 标签 | 详情页输出 | 栏目页输出 | 首页兑底 |
|---|---|---|---|
| `HY_PAGE_TITLE` | `海石 · 数据安全治理平台` | `产品中心` | `霍因科技` |
| `HY_PAGE_URL` | `/product/haishi-data-security.html` | `/product/` | `/` |
| `HY_PAGE_DESC` | 文章摘要 | 栏目描述 | 站点描述 |
| `HY_PAGE_KEYWORDS` | `""`（详情页无） | `""` | 站点关键词 |

**典型 SEO head**：
```html
<head>
  <title><HY_PAGE_TITLE /> · <HY_SITE_NAME /></title>
  <meta name="description" content="<HY_PAGE_DESC />">
  <meta name="keywords" content="<HY_PAGE_KEYWORDS />">
  <link rel="canonical" href="<HY_PAGE_URL />">

  <!-- Open Graph -->
  <meta property="og:title" content="<HY_PAGE_TITLE /> · <HY_SITE_NAME />">
  <meta property="og:url" content="<HY_PAGE_URL />">
  <meta property="og:description" content="<HY_PAGE_DESC />">
  <meta property="og:type" content="<HY_IF _condition="content.id">article<HY_IF _condition="!content.id">website</HY_IF>">">

  <!-- Twitter Card -->
  <meta name="twitter:title" content="<HY_PAGE_TITLE /> · <HY_SITE_NAME />">
</head>
```

**注意**：`og:type` 这种条件分支要嵌套 `HY_IF`（v1.0 不支持表达式 AND/OR）。

## 8. 导航标签（3 个）— 站点头部/底部 + 选中态

### 8.1 `HY_SITE_MENU _location="header|footer"` — 自动渲染

**菜单数据存 `site.settings.menu_header` / `site.settings.menu_footer`** (JSON，admin 后台「导航菜单」编辑)。

```html
<header>
  <HY_SITE_MENU _location="header" />   <!-- 渲染完整 nav HTML -->
</header>
<footer>
  <HY_SITE_MENU _location="footer" />
</footer>
```

**支持 4 种菜单项类型**：
- `category` — 指向栏目
- `page` — 指向站内详情页
- `external` — 外链
- `dynamic` — 动态子项（如"产品"展开所有子栏目）

### 8.2 `HY_NAV` (alias) — **已废弃**，请用 `HY_SITE_MENU`

### 8.3 `HY_MENU_ACTIVE _match="/path/"` — 选中态

返回 ` active`（CSS 拼到 class）或空字符串。**专门给静态模板用**（避免 JS 客户端判断）。

```html
<nav class="nav">
  <a href="/"          class="nav-link<HY_MENU_ACTIVE _match="/"          />">首页</a>
  <a href="/product/"  class="nav-link<HY_MENU_ACTIVE _match="/product/"  />">产品</a>
  <a href="/news/"     class="nav-link<HY_MENU_ACTIVE _match="/news/"     />">新闻</a>
  <a href="/contact/"  class="cta    nav-link<HY_MENU_ACTIVE _match="/contact/" />">联系我们</a>
</nav>
```

**匹配规则**：
| 当前 `page_path` | `_match` | 输出 |
|---|---|---|
| `index.html` | `/` | ` active` ✓ |
| `product/index.html` | `/product/` | ` active` ✓ |
| `product/haishi.html` | `/product/` | ` active` ✓（子页匹配父栏目）|
| `news/index.html` | `/product/` | `""` |

**配套 CSS**（推荐）：
```css
.nav a.active {
  color: var(--primary);
  background: var(--bg-blue);
  font-weight: 600;
  position: relative;
}
.nav a.active::after {
  content: "";
  position: absolute; left: 14px; right: 14px; bottom: 2px;
  height: 2px; background: var(--primary);
  border-radius: 1px;
}
```

## 9. 面包屑标签（2 个）

| 标签 | 说明 |
|---|---|
| `HY_BREADCRUMB` | 按 context 自动：详情页走 content.breadcrumb_html，栏目页走 category.breadcrumb_html，兑底 site.breadcrumb_html |

```html
    <span> / </span>

    <span> / </span>
    <span><HY_CONTENT_TITLE /></span>
  </HY_IF>

```

或直接用自动版：
```html
<nav class="breadcrumb"><HY_BREADCRUMB _separator=" / " /></nav>
```

**仅首页 / 落地页**可用。数据存 `site.settings.{hero,stats,products,cta}` (admin 后台「首页设置」编辑)。

### 10.1 `HY_SITE_HERO` — Hero 区

```html
<section class="hero">
  <HY_SITE_HERO />
</section>
```

```html
<div class="hero-badge"><span class="dot"></span> 数据要素可信流通</div>

  <a class="btn-primary" href="/product/">查看产品</a>
  <a class="btn-secondary" href="/contact/">联系我们</a>

```

### 10.2 `HY_SITE_STATS` — 4 个数字

```html
<section class="stats">
  <HY_SITE_STATS />
</section>
```

**输出**（前端 JS 数字递增动画）：
```html
<div class="stats-grid">
  <div class="stat">
    <div class="stat-value" data-count="100" data-suffix="+">0+</div>
    <div class="stat-label">企业客户</div>
```

### 10.3 `HY_SITE_PRODUCTS` — 3 个产品卡

```html
<section class="products">
  <HY_SITE_PRODUCTS />
</section>
```

**输出**：3 个产品卡片（带 icon + 标题 + 描述 + 链接）。

### 10.4 `HY_SITE_CTA` — 底部行动召唤

```html
<section class="cta">
  <HY_SITE_CTA />
</section>
```

**输出**：CTA 区（标题 + 副标题 + 2 个按钮）。

### 10.5 注意事项

- **必须在 site scope 或 home scope layout 使用**
- 站点的 `settings` 字段为空时，该块**不输出**（不显示空白）
- 数据结构由 admin 后台「首页设置」表单管理，不在模板里改

## 12. 列表项标签（16 个）— `HY_ITEM_*`

**仅 `<HY_CONTENTS>` 容器内**可用。自动按当前栏目过滤 + 排序 + 分页。

### 12.1 基础字段（11 个）

| 标签 | 输出 | 备注 |
|---|---|---|
| `HY_ITEM_ID` | UUID |  |
| `HY_ITEM_TITLE` | 文章标题 |  |
| `HY_ITEM_URL` | `/news/2026-06-08-post.html` |  |
| `HY_ITEM_SUMMARY` | 摘要（数据库 `excerpt` 字段） |  |
| `HY_ITEM_EXCERPT` | 同 `HY_ITEM_SUMMARY`（alias） |  |
| `HY_ITEM_COVER` | 封面图 URL |  |
| `HY_ITEM_DATE` | `2026-06-08` | **YYYY-MM-DD 短日期** (P3.8.9++) |
| `HY_ITEM_DATE_YEAR` | `2026` | **年份** (P3.8.9++++) |
| `HY_ITEM_DATETIME` | `2026-06-08T10:30:00+08:00` | ISO 完整 |
| `HY_ITEM_AUTHOR` | 作者名 | join User 表 |
| `HY_ITEM_CAT_NAME` | 所属栏目名 |  |
| `HY_ITEM_CAT_URL` | 所属栏目 URL |  |
| `HY_ITEM_TAGS` | `<a class="tag" href="/tag/xxx.html">xxx</a>...` | 预渲染 HTML |
| `HY_ITEM_HITS` | 阅读数 |  |
| `HY_ITEM_META _type="字段名"` | 任意 Content 字段 |  |

### 12.2 典型卡片模板

```html
<HY_CONTENTS _limit="12" _order="newest">
  <article class="card">
    <HY_IF _condition="content.has_cover">
      <a href="<HY_ITEM_URL />">
        <img src="<HY_ITEM_COVER />" alt="<HY_ITEM_TITLE />" loading="lazy" />
      </a>
    </HY_IF>
    <div class="body">
      <h3><a href="<HY_ITEM_URL />"><HY_ITEM_TITLE /></a></h3>
      <p class="excerpt"><HY_ITEM_SUMMARY /></p>
      <div class="meta">
        <span class="date"><HY_ITEM_DATE /></span>
        <HY_IF _condition="content.has_tags">
          <span class="tags"><HY_ITEM_TAGS _separator=" · " /></span>
        </HY_IF>
      </div>
    </div>
  </article>
</HY_CONTENTS>
```

### 12.3 `<HY_CONTENTS>` 容器属性

| 属性 | 用途 | 示例 |
|---|---|---|
| `_limit` | 限制条数 | `_limit="12"` |
| `_order` | 排序 | `_order="newest"` / `_order="oldest"` / `_order="popular"` |
| `_cat` | 限定栏目（不填用当前栏目） | `_cat="HY_CAT_SLUG"` 或 `_cat="news"` |
| `_tag` | 限定标签 | `_tag="python"` |
| `_page` | 分页（默认 1） | `_page="2"` |
| `_filter` | 过滤器链 | `_filter="truncate(80) | date('Y-m-d')"` |

### 12.4 `<HY_CONTENTS_EMPTY>` 空状态

```html
<HY_CONTENTS _limit="12">
  <article>...</article>
</HY_CONTENTS>
<HY_CONTENTS_EMPTY>
  <div class="empty">
    <p>该栏目暂无内容</p>
  </div>
</HY_CONTENTS_EMPTY>
```

**仅 `<HY_CATS>` 容器内**可用。

| 标签 | 输出 |

```html
<HY_IF _condition="cat.has_children">
  <section class="sub-cats">
    <h2>子栏目</h2>
    <ul>
      <HY_CATS _type="children">
        <li><a href="<HY_CAT_ITEM_URL />"><HY_CAT_ITEM_NAME /></a></li>
      </HY_CATS>
    </ul>
  </section>
</HY_IF>
```

**根栏目导航**（首页顶部）：
```html
<nav>
  <HY_CATS _type="root" _limit="8">
    <a href="<HY_CAT_ITEM_URL />"><HY_CAT_ITEM_NAME /></a>
  </HY_CATS>
</nav>
```

## 14. 容器标签（5 个）

| 标签 | 作用 | 闭合 |
|---|---|---|
| `HY_CONTENTS` | 内容列表循环 | 必须 `</HY_CONTENTS>` |
| `HY_CATS` | 栏目循环 | 必须 `</HY_CATS>` |
| `HY_IF` | 条件渲染 | 必须 `</HY_IF>` |
| `HY_INCLUDE` | 引入 partial 片段 | 自闭合 `<HY_INCLUDE _file="x.html" />` |
| `HY_TEMPLATE` | 引入同站点的其他 layout 模板 | 自闭合 `<HY_TEMPLATE _code="x" />` |
| `HY_CONTENTS_EMPTY` | 列表空状态 | 必须 `</HY_CONTENTS_EMPTY>` |

### 14.1 `HY_IF _condition="..."` — 条件

**支持的语法**：

| 语法 | 含义 | 示例 |
|---|---|---|
| 字面量 | `true` / `false` / `1` / `0` | `_condition="true"` |
| `xxx.has_yyy` | 字段 truthy 检查 | `_condition="content.has_cover"` |
| `!xxx.has_yyy` | 字段 falsy 检查 (P3.8.9++) | `_condition="!content.has_cover"` |
| `contents` / `cats` | 集合非空检查 | `_condition="contents"` |
| `contents.count OP N` | 数量比较 | `_condition="contents.count >= 5"` |

**不支持**：AND / OR / NOT 复杂表达式（v1.0），需嵌套 `HY_IF` 实现。

```html
<!-- 文章有封面才显示图片 -->
<HY_IF _condition="content.has_cover">
  <img src="<HY_ITEM_COVER />" />
</HY_IF>

<!-- 文章没封面用占位 -->
<HY_IF _condition="!content.has_cover">
  <div class="cover-placeholder">NEWS</div>
</HY_IF>

<!-- 列表超过 5 篇才显示"更多" -->
<HY_IF _condition="contents.count > 5">
  <a class="more" href="<HY_CAT_URL />">查看更多</a>
</HY_IF>
```

### 14.2 `HY_INCLUDE _file="x.html"` — 引入 partial

**partials 存 `partials/{file_name}.html`**，由 worker publish 时上传到 `public/{site_slug}/partials/`。

```html
<HY_INCLUDE _file="cookie-banner.html" />
<HY_INCLUDE _file="analytics.html" />
```

**注意**：partials 路径**站点全局共享**（不分 scope）。

### 14.3 `HY_TEMPLATE _code="x"` — 引入其他 layout 模板（P3.7+）

**layout 跨模板引用**（如 footer 想复用另一个 layout）。

```html
<HY_TEMPLATE _code="header-modern" />
<HY_TEMPLATE _code="footer-default" />
```

**特点**：
- 递归走完整 pipeline（子模板可继续引子模板）
- 防环：检测到递归会报 warning
- 最多递归 **8 层**

### 14.4 `HY_CONTENTS_EMPTY` — 列表空状态

见 §12.4。

## 15. 过滤器（Filter）系统

在属性值末尾加 `_filter="chain"` 链式处理。

**支持的过滤器**：

| 过滤器 | 用法 | 示例 |
|---|---|---|
| `truncate(N)` | 截断 N 字符 | `truncate(80)` |
| `date('fmt')` | 日期格式化 | `date('Y-m-d')` `date('Y年m月d日')` |
| `default('x')` | 空值兑底 | `default('无')` |
| `upper` / `lower` | 大小写 | `upper` |
| `strip_html` | 去 HTML 标签 | `strip_html` |
| `urlencode` | URL 编码 | `urlencode` |
| `abs_url` | 转绝对 URL | `abs_url` |
| `nl2br` | 换行转 `<br>` | `nl2br` |

**链式调用**（`|` 串联）：

```html
<HY_CONTENT_TITLE _filter="truncate(50) | default('无标题') | upper" />
<HY_CONTENT_DATE _filter="date('Y-m-d')" />
<HY_ITEM_SUMMARY _filter="truncate(120) | strip_html" />
```

**date 格式符**（PHP 风格 → Python strftime）：

| 格式 | 输出 | 说明 |
|---|---|---|
| `Y` | `2026` | 4 位年 |
| `m` | `06` | 2 位月 |
| `d` | `10` | 2 位日 |
| `H:i` | `14:30` | 时:分 |
| `Y-m-d` | `2026-06-10` | 标准日期 |
| `Y-m-d H:i` | `2026-06-10 14:30` | 日期+时间 |
| `Y年m月d日` | `2026年06月10日` | 中文 |

## 18. 常见错误 & 调试

### 18.1 标签拼错
```html
<HYitemtitle/>           <!-- ❌ 小写 -->
<HY__ITEM_TITLE/>        <!-- ❌ 多下划线 -->
<HY_ITEM_TITLE _class="x"/> <!-- ❌ _class 冲突（_ 前缀业务属性，业务字段用 class 即可） -->
```

### 18.2 容器没闭合
```html
<!-- ❌ 漏闭合 -->
<HY_CONTENTS _limit="6">
  <p>...</p>

<!-- ✅ 正确 -->
<HY_CONTENTS _limit="6">
  <p>...</p>
</HY_CONTENTS>
```

### 18.3 详情页用栏目标签 vs 列表项标签
```html
<!-- 详情页 (scope=content) 里:
     - HY_CAT_NAME  → 文章所属栏目（可用）
     - HY_ITEM_TITLE → 空（无列表循环）
     - HY_CONTENT_CAT_NAME → 同 HY_CAT_NAME
-->
```

### 18.4 标签在不该用的位置
- `HY_CONTENT_*` 仅详情页
- `HY_CAT_*` 仅栏目页 / 详情页
- `HY_ITEM_*` 仅 `HY_CONTENTS` 容器内
- `HY_CAT_ITEM_*` 仅 `HY_CATS` 容器内
- `HY_SITE_MENU` / `HY_MENU_ACTIVE` 主要 site scope

### 18.5 调试：看 render warning
admin 后台 → 模板 → 任意 layout → 编辑 → 「校验」按钮会显示：
- 未知标签 → `未知 HY_ 标签 XXX (不在白名单)`
- 未知条件 → `IF _condition="foo.bar"` 时 `未知条件: 'foo.bar'`
- 未知 filter → `_filter="foo()"` 静默忽略
- 模板环 → `模板递归超过 N 层`

发布后看产物 `public/{site}/index.html`，残留的 `<HY_XXX/>` 即未渲染的标签。
